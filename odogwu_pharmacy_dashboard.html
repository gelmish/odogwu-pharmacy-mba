How this was built: Raw transaction data was pulled from SQLite via SQL queries, pivoted into a boolean basket matrix (3,000 baskets × 25 products) using Pandas, then fed into the Apriori algorithm (mlxtend) with min_support=2%, min_confidence=30%, min_lift=1.2. Association rules surface product pairs that co-occur significantly more than chance — the lift score quantifies how much more likely the consequent is given the antecedent. Bundle prices are set at a 10% discount on the sum of individual prices, creating a clear customer value proposition while maintaining margin. A lift > 3.0 indicates a very strong cross-sell signal worth prioritising in a bundling experiment.
